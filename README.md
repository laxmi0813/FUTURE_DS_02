## 📌 Project Overview

This project analyzes customer churn behavior using Power BI.
The objective is to understand why customers leave and identify ways to improve retention.

---

## 🛠️ Tools Used

* Power BI
* Microsoft Excel

---

## 📂 Dataset

The dataset includes customer details such as:

* Gender
* Tenure
* Contract Type
* Monthly Charges
* Tech Support
* Internet Service
* Payment Method
* Churn Status

---

## 📊 Dashboard Features

* KPI Cards (Total Customers, Churn Rate, Avg Charges, Avg Tenure)
* Churn by Contract Type
* Churn vs Monthly Charges
* Churn Trend by Tenure
* Tech Support Impact on Churn
* Customer Segmentation (Matrix by Tenure Group)
* Interactive Filters (Gender, Contract, Payment Method, Internet Service)

---

## 🔍 Key Insights

* Month-to-month customers have the highest churn
* Customers without tech support are more likely to leave
* Early-stage customers (0–3 months) show high churn
* Higher monthly charges increase churn probability

---

## 💡 Recommendations

* Promote long-term subscription plans
* Improve onboarding experience
* Provide proactive customer support
* Offer pricing incentives for high-risk customers
